Inventář pro RPG hru

V této úloze budete vytvářet několik tříd a interface. 

Začněte s předpřipraveným kódem.

Předpřipravenou statickou metodu Test() a metodu Main ponechte úplně nahoře. Test neměňte, main si můžete přirozeně upravit / rozšířit dle vlastních potřeb, abyste zkoušeli vše, co potřebujete

V testu máte nějaké vytvpřené objekty (může tam ale být ještě syntaktická chyba) i ukázku výsledného výpisu. Při ladění si tento kód nebo jeho části libovolně zkopírujte do Main a pak třeba postupně odkomentovávejte.

Připravte projekt s těmito třídami a rozhraními (jde o fiktivní RPG hru)

Interface IUsable

  • Označuje objekty, které postava může použít
  • Interface předepisuje pro čtení int vlastnost MinLevel, která říká, jakou minimální úroveň postava musí mít, aby objekt mohla použít
  • Interface předepisuje metodu Use, která vrací string (znamená použití věci)

Interface IStorable

  • Označuje objekty, které lze uložit do inventáře
  • Předepisuje veřejně čitelnou vlastnost int Weight

Třída Spell

  • Představuje kouzlo
  • Implementuje IUsable
  • V konstruktoru očekává řetězce Name (jméno), Cast (zaříkadlo) a integer MinLevel, které si uloží a vystaví je ven jako vlastnosti veřejné pro čtení
  • Při použití Spell.Use() vrací řetězec typu "Casting Magic Arrow: Vas Ort Flam", s tím, že mázev Magic Arrow a zaříkadlo Vas Ort Flam jsou uložené hodnoty.

Abstraktní Třída Item

  • Označuje nějakou - jakoukoli - věc
  • Obsahuje vlastnost Name, která říká, jak se věc jmenuje
    • veřejně lze číst
    • konstruktor ji nastaví

Třída Coin

  • rozšiřuje Item
  • implementuje IStorable
  • její váha je vždy 1
  • Má veřejnou vlastnost int Value
    • veřejně lze číst
    • konstruktor ji nastaví
  • Konstruktor také zajistí, aby Name bylo Coin (použijte konstruktor bázové třídy)

Třída Weapon

  • rozšiřuje Item
  • implementuje IStorable (jde dát do inventáře)
  • implementuje IUsable (lze použít)
  • Name, MinLevel a Weight přijme v konstruktoru a uloží nebo předá konstruktoru bázové třídy
  • Má veřejnou vlastnost int MaxDamage
    • veřejně lze číst
    • konstruktor ji přijímá a nastaví
  • Při použití Weapon.Use() vypíše řetězec typu "Attacking with my Axe, damage is 13"
    • název, např. "Axe" odpovídá uložené hodnotě Name
    • damage je náhodné číslo mezi 0 a uloženou vlastností MaxDamage

Třída Character

  • Označuje nějakou postavu

  • Má veřejné int vlastnosti MaxWeight a Level, které udávají, kolik toho postava unese a jakou má úroveň

    • veřejně je lze číst
    • konstruktor je nastaví

  • Obsahuje položku Backpack (list objektů, které implementují IStorable)

  • Existuje metoda bool Store(IStorable thing), která zkusí uložit do batohu (do listu Backpack) předaný thing.

    • Pokud se thing kvůli váze (porovnáváme Weight všech věcí v batohu dohromady a MaxWeight) nevejde, vrátí false;
    • Pokud se vejde, přidá ho a vrátí true;

  • Existuje metoda void UseAll(IUsable[] tools), které předáte pole použitelných věcí a ona z nich použije všechny, které dokáže (pozor, věci mají MinLevel, postava Level, hlídejte, že to postava dokáže použít)

  • Bonus: napište metodu TotalMoney(), která bude vracet, kolik peněz v batohu postava má (jakou celkovou hodnotu)
