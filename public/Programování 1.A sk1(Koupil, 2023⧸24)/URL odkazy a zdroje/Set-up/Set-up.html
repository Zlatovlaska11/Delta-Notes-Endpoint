Seznam nástrojů, co potřebujete pro fungování v hodinách:

Visual studio 2022

1. Stáhněte si Visual Studio Community. Stáhne se vám Visual studio Installer, skrz který provede instalaci.

2. Instalujte pouze Vývoj desktopových aplikací pomocí .NET.


3. Při zakládání nové Konzolové aplikace je nutné zaškrtnout/ponechat "Do not use top-level statements"


4.  Doporučuji přepnout VS do angličtiny, aby vám chybové hlášky dávaly smysl. Je potřeba v takovém případě stáhnout jazykový balíček, opět skrz Installler. V záložce Jazykové sady vybrat angličtinu.


4a. Následně je nutné přímo ve VS jazyk změnit: Nástroje-> Možnosti -> Prostředí -> Mezinárodní nastavení. Zde změnte jazyk na English.


5. Následně je třeba vypnout automatické dopisování kódu, které v rámci výuky Programování je zakázáno. V rámci VS v menu Tools ->Options -> Intellicode -> General. Nastavte takto:
