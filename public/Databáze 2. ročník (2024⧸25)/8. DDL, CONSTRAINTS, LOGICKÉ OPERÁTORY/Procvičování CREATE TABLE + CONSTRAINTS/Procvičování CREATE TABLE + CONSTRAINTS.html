CONTSTRAINTS - omezující podmínky

1) NOT NULL - hodnota ve sloupci nesmí být NULL

2) UNIQUE - jedinečnost - zakázány duplicity hodnot    

3) FOREIGN KEY (FK)- cizí klíč, odkazuje (REFERENCES) na sloupec jiné tabulky

4) PRIMARY KEY (PK) - primární klíč, který je zároveň UNIQUE a NOT NULL a dále se automaticky vytváří tzv. INDEX (pro rychlejší přístup k PK)

5) DEFAULT - předdefinovaná hodnota nebo také výchozí hodnota, která je použita v okamžiku, kdy není vložena hodnota vlastní do daného sloupce, příklad: jmeno VARCHAR2(30) DEFAULT 'Donald'

6) CHECK - určuje, které hodnoty mohou být ve sloupci (podmínka pro hodnoty ve sloupci), příklad: PLAT NUMBER CHECK PLAT BETWEEN 20000 AND 40000
