Jedná se o programové vybavení počítače, jinými slovy sada všech počítačových programů umístěných v počítači.

Systémový software

Programové vybavení počítače, které umožňuje spouštění nebo zpracování aplikačního software

Operační systém

Sada programů (software) sloužících především k tomu, aby byly aplikačním programům transparentním způsobem zpřístupněny prostředky (hardware) počítače, aby vytvářel potřebné operační prostředí pro chod aplikací.

Mezi základní funkce patří rozdělení systémových prostředků (operační paměť, disk, periferní zařízení), ale také strojového času a přístupu ke komunikačním tokům, dále pak systémové prostředky nehmotné povahy (např. sada písem). Umožňuje chod více aplikací současně, rozděluje jim strojový čas, izoluje aplikace navzájem od sebe a umožňuje jim vzájemnou komunikaci. Aplikace má tedy ke svému chodu pouze prostor vymezen operačním systémem, pokud se tento prostor pokusí překročit tak nedojde (v dobře napsaném operačním systému by k tomu nemělo dojít) ke zhroucení počítače, ale pouze ke zhroucení aplikace samotné.

Operační systémy osobních počítačů řady PC

  • Unix (Solaris, BSD, GNU/Linux)
  • DOS (MS-DOS,FreeDOS)
  • Microsoft Windows  
      • Nástavby MS-DOS (Windows 95, Windows 98, Windows ME)  
      • s jádrem Windows NT (Windows 2000, Windows XP, Windows Vista,  Windows 7, Windows 8)  
      • serverové Windows (Windows 2000 Server, Windows 2008 Server, Windows 2012 Server)

Firmware

Firmware je označení pro software, který je napevno zabudovaný v hardwaru. Jedná se např. o BIOS počítače v paměti ROM nebo programové vybavení mikro-ovladače v počítačové tiskárně. 

Aplikační software

Aplikační software nebo aplikační programové vybavení znamená takové programové vybavení počítače, které je určeno pro přímou či částečně nepřímou interakci s uživatelem. Účelem aplikačního software je zpracování a řešení konkrétního problému (uživatele). Typicky má aplikační software grafické nebo textové rozhraní pro interakci s uživatelem.

Nejčastější typy:

  • databázové systémy
  • ekonomické a informační systémy
  • grafické editory
  • hry

Kancelářské aplikace

Kancelářská aplikace, někdy nazývaná též "kancelářský balík", je kolekce kancelářských programů určených pro použití pracovníků zpracovávající data (ve velké míře texty). Složky jsou obvykle distribuovány spolu, mají konzistentní uživatelské rozhraní a obvykle se mohou na sebe vzájemně vázat.

Nejčastěji používané kancelářské programy jsou:

  • Textový procesor
  • Tabulkový procesor
  • Prezentační program
  • Databázový program

Mezi nejoblíbenější kancelářské balíky řadíme Microsoft Office, který se stal standartem pro ostatní kancelářské balíky (OpenOffice.org, LibreOffice, v kontextu přípon souborů, kde ostatní balíky musí mít schopnost otevírat/upravovat tyto dokumenty (např. .doc, .ppt ).

Softwarové licence

Softwarová licence je právní nástroj (obvykle prostřednictvím smluvního práva, s nebo bez tištěných materiálů) upravující používání nebo další šíření software. Umožňuje jednotlivci nebo skupině uživatelů používat kus softwaru. Téměř všechny aplikace jsou licencovány, nikoliv prodávány.

 Existuje celá řada různých typů softwarových licencí. Některé z nich jsou založeny na počtu počítačů, na kterých může licencovaný program běžet, zatímco jiné jsou založeny na počtu uživatelů, kteří mohou program používat. Většina softwarových licencí určených pro osobní počítače vám umožní spustit program pouze na jednom počítači a pořizovat kopie softwaru pouze pro účely zálohování.

Proprietární software

Proprietární software nebo "software uzavřeného zdrojového kódu" je počítačový software licencovaný na základě výlučného zákonného práva držitele autorských práv s úmyslem, aby držitel licence měl dané právo užívat software pouze za určitých podmínek a měl omezená práva, jako například úpravy, sdílení, studium nebo redistribuce. Ve většině případů zdrojový kód proprietárního software není k dispozici.

Svobodný software

Někdy také nazývaný free software. Jedná se o software, ke kterému může být k dispozici také zdrojový kód, spolu s právem tento software používat, upravovat a distribuovat. Naprostá většina svobodného software je zdarma, ačkoliv to není podmínkou. Free software tedy znamená volné užití softwaru bez zdrojového kódu.

Základní svobody:

  • svoboda používat program za jakýmkoliv účelem
  • svoboda studovat, jak program pracuje a možnost přizpůsobit ho svým potřebám
  • svoboda redistribuovat kopie programu
  • svoboda vylepšovat program a zveřejňovat zlepšení, aby z nich mohla mít prospěch celá komunita

GNU (GNU's Not Unix) zajišťuje tyto základní svobody svobodného software a někdy je také nazývána "copyleft" licencí. Copyleft licence říká, že pokud redistribuujete originální nebo pozměněnou verzi programu, musíte tuto verzi redistribuovat pod stejnou licencí pod jakou jste získali původní program.

GNU General Public License, GNU GPL (česky „obecná veřejná licence GNU“) GPL je nejpopulárnějším a dobře známým příkladem silně copyleftové licence, která vyžaduje, aby byla odvozená díla dostupná pod toutéž licencí.

Open Source software

Někdy také otevřený software (zkratka OSS) je počítačový  software s otevřeným zdrojovým kódem. Otevřenost zde znamená jak technickou dostupnost kódu, tak legální (ne)dostupnost, dodržování licence softwaru. Licence je velmi důležitá, jelikož specifikuje, jaká práva k otevřenému kódu získá a jak s nim může nakládat jeho uživatel. Některé licence (ku příkladu GNU) například dovolují uživatelům zdrojový kód upravovat a distribuovat (na rozdíl od proprietárního softwaru).

Vysvětlení OSS x FS:

"Software, který má dostupný zdrojový kód a jehož licenční ujednání poskytuje uživateli právo využívat program pro libovolné účely, právo studovat funkci programu a měnit ji dle svého uvážení, právo dále šířit kopie původního programu nebo pozměněné verze programu. "Open source software" a "svobodný software" ("free software") lze v podstatě považovat za synonyma, avšak existuje mezi nimi nepatrný, spíše ideologický rozdíl. Dvojí pojmenování je dáno vznikem dvou nezávislých iniciativ (Free Software Foundation a Open Source Initiative), které mají odlišný přístup k tomuto softwaru především z hlediska licencování."
